# Hand-curated seed list of institutional asset managers, PE/hedge funds,
# bank-owned private wealth arms, and RIA/advisory firms that must NOT be
# classified as family offices. Used as a substring match against entity
# names during the qualification gate (see config.EXCLUSION_REASON_INSTITUTIONAL).
#
# One token per line. Lines starting with # are comments. Match is
# case-insensitive substring against the entity_name field.
#
# Categories (per methodology spec):
#  - Tier-1 institutional asset managers
#  - PE / hedge fund / alternative investment firms
#  - Bank-owned private banking / wealth management arms
#  - RIA / advisory-centric firms (third-party capital, not family wealth)
#  - Corporate family-office arms of public/operating companies
#
# This is a *seed* list (~80 names). It is intentionally conservative —
# false negatives (a real SFO that gets excluded) are recoverable via
# manual review; false positives (an institutional firm that ships as an
# SFO) are disqualifying. The list will grow as the pipeline surfaces
# new false-positive patterns.
